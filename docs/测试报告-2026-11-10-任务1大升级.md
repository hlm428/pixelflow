## 二、逐项明细

### 1.1 改名 ✅

- 源码全局检索：旧名只剩 `src/lib/seed.ts` 的 `LEGACY_SEED_NAMES` 迁移清单（不显示在界面，作用是把老用户浏览器里的旧名示例项目删掉重灌成新名——改名生效必需）。
- 浏览器实测（首次安装 + 老数据升级两条路径都测了）：
  - 首次打开：项目列表出现《重生之我住进月见公寓》，无旧名。
  - 模拟老用户（种子标记回 v4 + 刷新触发迁移）：同名示例项目被替换成新名。
- `docs/AI视频工作台-ZCode大项目.md` 里的旧名一并改掉。

### 1.2 拆分镜按故事语义拆 ✅

- 柑橘项目实测：一句话故事 → 检测到 **6 个情节点** → 点拆分镜生成 **6 条分镜**，每条都有真实画面描述（雨夜校门分伞 / 共伞走过商店街 / 便利店买橘子汽水 / 河堤长椅碰杯 / 纸条「明天见」/ 并排看晚霞），无一条「待补充」空模板。
- 空故事兜底：完全不写故事时最多生成 6 条占位（任务书允许的下限），有故事内容时绝不凑数。
- 单镜时长：下拉 5 秒 / 10 秒 + 新增「按故事自动算」按钮（实测：6 情节 × 10s ≈ 目标 60s，自动算出 10 秒并弹提示）。
- 覆盖确认弹窗：明确列出「当前已有 6 个分镜、6 条提示词、0 个片段、0 条配音。重新拆分会覆盖这些内容……」，损失一目了然。
- 撤销：拆分前自动备份，拆完有「↩️ 撤销本次拆分」横幅。
- **当场修复 ①**：撤销入口原本只在当页有效，去别的页再回来就丢了 → 备份持久化到 localStorage，导航离开再回来横幅还在，撤销后分镜、提示词、角色卡计数全部恢复原样。
- **当场修复 ②**：角色卡「出现于分镜」计数原本会被拆分清零（新分镜文本里没写角色名，自动识别匹配不到）→ 拆分时文本匹配不到就按位置从旧分镜继承关联。实测：拆分前后小满/小雪都是「出现于 6 个分镜」，计数不丢。

### 1.3 每条分镜自动带完整提示词 ✅

拆完即自动生成 v1 提示词，实测第 4 镜完整内容：

```
【视觉锁定】Japanese anime film style, cinematic anime photography, 16:9 cinematic framing,
same light source and same color temperature throughout, realistic texture without over-smoothing,
relaxed natural expressions, no posing, no subtitles, no watermark, no readable text anywhere in frame
【场景】河堤日落碰杯；
【运镜】跟随
【光线】日落暖橙色光
【接力】承接上一个分镜（#3）的尾帧，动作和位置连续……
```

- 五要素齐：画面描述（场景）、英文提示词（视觉锁定）、运镜、光线、风格词（沿用项目风格「动漫」，全片一致不乱跳）。
- 光线自动从文本识别（「日落」→ 日落暖橙色光），没写的按风格兜底。
- 含 `no readable text anywhere in frame` 硬规则——招牌、纸条上的字不会出现在画面里，文字后期叠加，符合任务书要求。
- 提示词带版本号（v1）+ 接力句（第 2 镜起），对齐柑橘 #01 规格。

### 1.4 接入视频生成 API ✅

- 接入两家入口：**fal.ai（推荐，浏览器直连，含可灵 Kling / 海螺等模型）** + **自定义接口（自建代理 / OpenAI 兼容聚合站）**。设置页选服务商、填模型 id、填 API Key，有「🔌 测试连接」按钮。
- API Key 不写死在代码里：只存浏览器 localStorage，界面上写明「不上传」。
- 状态流转：片段 待生成→生成中→待质检→通过/失败；失败时弹明确错误信息（HTTP 状态码 + 服务端返回内容），不悄悄失败。
- **耗时/花费真实记录（本轮新增）**：每次生成实测「提交→出片」全程毫秒数存进片段记录（genMs），并按模型单价 × 实际时长折算估算花费（cost）。看板新增两张真实数字卡：「生成总耗时」「生成成本」，生成后不再是 0。成功提示里也直接报「本次耗时 X 分 Y 秒，估算花费 ¥Z」。
- **近 30 天生成量折线图（本轮新增）**：柱状图改为 SVG 折线图，每天一个数据点，鼠标悬停显示「日期：N 条 / ¥花费」，峰值一眼可见。
- 成本统计表保留（按模型次数 × 估算单价），明确标注「估算，以平台计费为准」。
