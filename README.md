# PixelFlow AI 视频工作台

一个能真正用来做 AI 视频的完整工作台：从写故事、拆分镜、建角色卡，到生成片段、质检、拼接成片、发布到各平台。全部前端本地运行，不需要后端，数据不出浏览器。

基于 PixelAIGC 的 16 步超长 AI 视频工作流（10 秒一片段、角色卡锁定、接力规则、QC 检查、ffmpeg 拼接）。

## 安装

```bash
npm install
npm run dev        # 开发：http://localhost:5173
npm run build      # 构建到 dist/（纯静态，任意静态服务器可跑）
npm test           # 单元测试（70 个用例）
npm run preview    # 预览构建产物
```

要求 Node 18+。首次启动会自动灌入 5 个示例项目（含全部角色卡、分镜和提示词）和 260 条提示词模板。

## 推荐工作流

1. **项目页**新建项目（一句话故事 + 目标时长 + 画幅 + 风格）
2. **故事分镜页**点「拆分镜」，微调每段的画面描述和运镜
3. **角色卡页**建角色卡（只定脸、头发、衣服！道具锁定写进备注）
4. **提示词页**点「按公式生成」，从模板库补光线/情绪词
5. 把提示词丢给视频模型（Muse / 即梦 / 可灵…），生成 10 秒片段
6. **片段页**上传候选（每镜 1–6 个），对比后⭐标最优
7. **QC 页**过 15 项清单，不过的回提示词页改了重抽（最多重试 2 次）
8. **配音页**成片剪好后再配音，上传音频做对齐检查
9. **拼接页**下载 run.sh / run.bat，和片段文件放同一目录运行（本机需装 ffmpeg）
10. **拼接页**底部复制四平台发布文案（自动带 AI 声明）

## 数据管理

- 数据全部存在浏览器 **IndexedDB**（9 张表）+ **localStorage**（设置/供应商），不联网不上传
- 换电脑/备份：设置页「导出全部数据」→ 新机器「导入全量备份」
- 单项目迁移：项目卡片「导出」/ 项目页「导入」
- ⚠️ 无痕模式 = 关浏览器就删库；清浏览器数据 = 删库。重要项目先导出
- 想重置示例数据：设置页「清空全部数据」（需输入"清空"确认）后刷新

## 关键规则（写进代码里的）

- **角色卡锁定**：卡只定脸/头发/衣服，原文逐字拼进提示词开头
- **接力规则**：编号 ≥2 的分镜自动带「承接上一个分镜的尾帧」
- **状态机**：待生成 → 生成中 → 待质检 → 通过/失败 →（重试 ≤2）→ 放弃
- **配额**：每日片段上限默认 100，80% 变黄 100% 变红
- **AI 声明**：发布文案自动带「本片全部画面由 AI 生成，非实拍」；画面内不烧录水印文字
